# hingespan

Hinge CSV/TSV span tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/hingespan/

## Install / run

```bash
git clone https://github.com/theworker02/hingespan.git
cd hingespan
node src/cli.js
node --test
```
